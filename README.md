# 港岛树洞 · 异闻录 — O-Camp 破冰大屏

香港大学迎新营破冰活动的大屏主持工具。单文件、离线可用、双击即开。

## 三个环节

1. **自我介绍** — 大转盘随机点名，抽中的人按提示题介绍自己（提示题可编辑）
2. **逛三园 / 击鼓传花** — 双玩法可切换；传花停到谁、逛三园接不上谁，就转动大转盘抽取惩罚题回答（内置 30 道香港生存 / HKU 冷知识题，可编辑）
3. **你有我没有** — 浓缩完整规则大屏展示，全员真人玩手指，线下进行

## 功能

- 🎡 大转盘抽人 / 抽题（罗盘样式，转盘音效 + 落点彩带）
- 🥁 击鼓传花：虚拟传花动画 + 内置合成鼓点节拍，支持上传自己的背景音乐
- ⏱ 逛三园：类别（港风 + 通用，可编辑）+ 倒计时圆环
- 👥 名单管理：添加 / 编辑 / 删除 / 批量粘贴 / 随机排序
- ✨ 全站动效：星空流萤背景、点击波纹、光标拖尾、页面转场
- 🔊 每次点击都有合成音效，可一键开关
- 💾 数据保存在浏览器 localStorage + IndexedDB（音乐），不上传服务器
- 🖥 1920×1080 大屏投影优化，支持全屏与键盘快捷键

## 使用

直接双击 `index.html` 即可。活动前建议：

1. 打开「名单管理」录入参与者
2. 在「设置」里按需调整提示题库 / 惩罚题库 / 逛三园类别 / 倒计时秒数
3. 可上传背景音乐（约 20MB 以内，存本机）

## 键盘快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 | 转盘抽人 / 开始·停止传花 / 逛三园倒计时 |
| 回车 | 揭晓答案 / 下一题 |
| Esc | 关闭弹窗 |
| F | 全屏切换 |

## 技术

原生 HTML + CSS + JavaScript，零依赖、无外部请求，单文件离线可用。主题「港岛树洞·异闻录」暗黑神秘风（黑底 / 深紫 / 品红霓虹）。
